## Actions

### `set-status`: Update my status

- **Kind:** send a CoT event
- **Triggered by:** Radio buttons `#me-status-pick` (change)
- **What it does:** Attach myStatus to my outgoing position report so other devices color my icon.

### `open-new-incident`: New incident

- **Kind:** open a screen
- **screen:** `new-incident`
- **Triggered by:** Button `#new-incident-btn` (click)
- **What it does:** Open the new-incident form with a blank draft.

### `create-incident`: Create incident

- **Kind:** send a CoT event
- **Triggered by:** Button `#ni-create` (click)
- **What it does:** Validate type + location, add an incident built from the draft* fields to incidents, broadcast it as CoT, return to the main pane.

### `open-incident`: Open incident

- **Kind:** custom behavior
- **Triggered by:** Repeating list `#incident-list` (itemClick)
- **What it does:** Show the tapped incident's details, ranking units by distance and walking time from its location.

### `assign-unit`: Assign unit

- **Kind:** send a CoT event
- **Triggered by:** Table `#unit-table` (rowClick)
- **What it does:** Assign the tapped unit to the open incident; send that unit's device an alert CoT.

### `pick-location`: Pick location

- **Kind:** pick a point on the map
- **Triggered by:** Pick point on map `#ni-location` (change)
- **What it does:** Let the user tap the map; store the point in draftLocation and look up its what3words address if a key is set.
